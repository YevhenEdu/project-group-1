# project-group-1

#Передумови
Встановити Python 3.13.5

# Запуск:
1. Відкрийте термінал у кореневій папці проєкту
2. Запустіть програму:
`python main.py`
або
`python3 main.py`

3. Вихід з програми:
наберіть `exit`
або використайте Ctrl + C/Ctrl + D

# linter
Створити venv, якщо ще немає
```python3 -m venv .venv```

Встановити лінтер ruff
```
source .venv/bin/activate
pip install ruff
```

Запуск лінтера:
```
source .venv/bin/activate
ruff check .
```

# Доступні команди:
## Контакти
* `help` - показати доступні команди
* `exit` - вийти з бота
* `list` - показати список контактів
* `add` - додати контакт
* `edit` - редагувати контакт
* `del` - видалити контакт
* `find` - знайти контакт
* `search` - знайти контакт за ключовим словом
* `upcoming_birthdays` - список контактів з днем народження через * днів

## Нотатки
* `notes` - показати список нотатків
* `add-note` - додати нотатку
* `edit-note` - редагувати нотатку
* `del-note` - видалити нотатку
* `find-note` - знайти нотатку за ключовим словом
* `show-note` - показати нотатку
* `tags` - показати список тегів
* `find-by-tag` - знайти нотатку за тегом
