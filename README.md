#Передумови
Встановити Python 3.13.5

# Запуск:
1. Відкрийте термінал у кореневій папці проєкту
2. Запустіть програму:
`python main.py`
або
`python3 main.py`

3. Вихід з програми:
наберіть `exit`
або використайте Ctrl + C/Ctrl + D

# linter
Створити venv, якщо ще немає
`python3 -m venv .venv`

Встановити лінтера ruff
`
source .venv/bin/activate
pip install ruff
`

Запуск лінтера:
`
source .venv/bin/activate
ruff check .
`
